# image-builder

NOVERA shop 운영 이미지를 기준 사이즈대로 만들고 내려받는 사내 툴.
PRD: Notion `[PRD] NOVERA shop 이미지 빌더 (인터널 툴)`

`index.html` 하나로 동작합니다. 빌드 없이 브라우저로 열면 되고, 이미지는 브라우저(Canvas) 안에서만 처리합니다.
외부 의존성은 Pretendard 웹폰트(jsDelivr)와 JSZip(cdnjs) 두 개입니다.

```bash
python3 -m http.server 8000   # 저장소 루트에서
# → http://localhost:8000/image-builder/
```

### 배포

- **단독 프로젝트(권장)**: Vercel에서 이 저장소로 새 프로젝트를 만들고 **Root Directory = `image-builder`** 로 지정하면 `image-builder/vercel.json` 설정으로 빌드 없이 정적 배포됩니다(예: `novera-image-builder.vercel.app`). `audit/`·`README.md` 는 `.vercelignore` 로 제외됩니다.
- 기존 `novera-shop-proto` 프로젝트에서는 `/image-builder/` 경로로도 열립니다(루트 `vercel.json` 이 함께 복사). 브랜치 프리뷰는 Vercel 로그인이 필요합니다.

## 슬롯과 기준 사이즈

기준은 **운영 등록 이미지 전수 실측(2026-10-26, 1,391개) × Figma 운영 가이드라인** 이 일치하는 값입니다.
어드민 권장 사이즈 안내는 기준으로 쓰지 않고, 업로드 형식·용량 제약만 반영했습니다.

| 탭 | 편집(@1x) | 출력 | 근거 |
|---|---|---|---|
| 컬렉션 배너 | 375×140 | 750×280 | Figma = 운영 6/6 |
| 띠배너 | 375×60 | 750×120 | Figma (운영 등록 없음) |
| 상품 썸네일 | 500×500, 배경 #F3F3F6 고정, 320 영역 | 1000×1000 PNG ≤ 2MB | Figma = 운영 일치값 |
| 아티스트 썸네일 | 500×500, 원형 마스크 | 1000×1000 | 운영 최빈값 (Figma 가이드 없음) |
| 메인 배너 *(일시 숨김)* | 모바일 375×320 · 데스크탑 520×280 동시 편집 | 750×640 · 1040×560 (ZIP) | Figma = 운영 모바일 3/3 · 데스크탑 1/3 |

메인 배너는 탭에서만 빠져 있고 기능은 그대로입니다. `PRESETS.main.hidden` 을 지우면 다시 나타납니다.

슬롯 규격·가이드 문구는 `index.html` 상단 `PRESETS` 한 곳에 모여 있습니다. 가이드가 개정되면 여기만 고치면 됩니다.

## 기능

UI는 NDS 토큰과 컴포넌트 스펙(Checkbox `358:1954`, Badge `407:1070` 등)을 따릅니다.

- 프리셋 선택, 가이드 탭(Figma 가이드 섹션별 도식 · 설명 · 버전 · 원본 링크, 도식은 눌러서 크게 보기). 도식은 가이드 수치로 직접 그린 SVG라 외부 이미지를 쓰지 않음
- 이미지 입력: 파일 · 드래그 앤 드롭 · 붙여넣기 · URL(CORS 허용 주소만)
- 드래그로 이동, 휠로 확대/축소, 맞춤 · 중앙 정렬, 밝기·대비·채도
- 메인 배너 모바일/데스크탑 동시 편집 (편집 대상 칩)
- 가이드 오버레이: 세이프 영역 · 크롭 영역 · 320 영역 · 원형 마스크. 캔버스 상단 툴바에서 켜고 끔 (저장 시 제외)
- 메인 배너 운영 화면 미리보기: 딤 0→16→64%, Label/Title, 페이지네이션 (저장 시 제외) + 글자 수 카운터
- 컬렉션·띠배너 3단 레이어 템플릿, `현행 운영`(텍스트 합성) / `가이드 준수`(텍스트 제외) 모드
- 컬렉션·띠배너 배경색 선택(스와치 + 직접 선택). 그라디언트는 배경색에 투명도만 달리해 자동 적용, 텍스트 색은 배경에 맞춰 자동(흰색으로 AA가 안 나오면 배경색을 어둡게 한 키 컬러) 또는 직접 지정, WCAG AA 대비 계산
- 상품 썸네일: 배경이 있는 이미지는 모서리 12px 라운드, "자동 누끼"(가장자리에서 이어지는 단색 배경 제거 + 여백 자르기, 브라우저 안에서만 처리, 원본으로 되돌리기). 배경이 단색이 아니거나 별도 편집이 필요하면 디자이너 요청 안내
- 텍스트 입력 전에는 플레이스홀더("헤드라인 최대 두 줄이에요" 등)가 미리보기에 그대로 보이고, 입력하면 그 텍스트로 바뀜. 플레이스홀더는 내보내는 이미지에 들어가지 않음
- 실제 노출 미리보기: 컬렉션 모바일 375×140 / 데스크탑 520×140(상·하 27px 크롭), 띠배너 모바일 / 데스크탑, 아티스트 원형 52·40px
- 내보내기 전 체크리스트 (자동 판정 + 수동 체크, 미통과 시 경고 후 내보내기 허용)
- 파일명 규칙 `{슬롯}_{식별자}_{mobile|desktop}_{가로}x{세로}_{YYMMDD}.{ext}`, ZIP 일괄, 용량 한도 검사
- 어드민 연결("어드민에서 등록하기"): 다운로드 후 해당 어드민 등록 화면 링크와 "어느 칸에 어떤 파일" 안내를 띄움. 보안상 API 업로드·로그인 정보는 다루지 않고, 업로드는 사용자가 직접 함

## 하지 않은 것

- 어드민 API 업로드(보안상 하지 않음 — 링크만 연결), 작업 저장/불러오기, 팝업 프리셋(기준 사이즈 미확정), 상세 이미지 분할(제외됨)
- 딤 방향은 가이드 본문과 도식이 서로 반대라(PRD 열린 질문) 이미지 쪽 투명 → 텍스트 쪽 불투명으로 구현

## audit/

PRD의 기준 사이즈를 낸 운영 이미지 실측 스크립트입니다. 분기마다 다시 돌려 기준을 갱신합니다.

```bash
cd image-builder/audit
python3 collect.py slots.json          # 공개 API에서 슬롯별 파일 ID 수집
python3 measure.py slots.json dims.json  # 픽셀 크기·포맷·용량 측정
python3 bg.py                          # 상품 썸네일 배경색(#F3F3F6) 판정 — Pillow 필요
```
